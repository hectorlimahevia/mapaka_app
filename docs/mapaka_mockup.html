Nota d'implementació: aquesta maqueta és HTML/CSS/JS estàtic per validar navegació, color i tipografia. La lògica real (validació d'aprovacions, ledger de moviments, regles de paga, sessions de temps de pantalla) es construirà amb Vue 3 + Spring Boot segons la documentació funcional ja existent — un cop aprovada aquesta maqueta, es generaran els prompts per implementar-ho.

Sobre el bloc de la tauleta: en producció, el "toc" de l'objecte NFC no l'escaneja la pàgina web (l'API activa Web NFC no funciona a iOS ni a escriptori) — l'etiqueta porta gravada una URL i és el sistema operatiu qui la llegeix i obre l'app. Aquí el botó "Simular toc" només substitueix aquest gest físic perquè puguis provar el flux. El cronòmetre d'aquesta demo també va accelerat (1 segon real ≈ 1 minut simulat) perquè puguis veure el repartiment sense esperar una sessió real.
